# 👑 AURUM – Premium T-Shirt Koleksiyonu

**AURUM**, lüks ve modern bir e-ticaret deneyimi sunmak amacıyla tasarlanmış, tamamen **frontend** teknolojileriyle geliştirilmiş bir web sitesi şablonudur. Altın, siyah ve beyaz renklerin zarafetini bir araya getirir; premium bir t-shirt koleksiyonunu görsel efektler ve akıcı sayfa geçişleriyle sergiler.

> **Not:** Bu proje bir frontend şablonudur. Gerçek ödeme altyapısı veya veritabanı bağlantısı içermez.

---

## ✨ Özellikler

### 🎨 Tasarım
- **Altın – Siyah – Beyaz** renk paleti
- Calibri yazı tipi, 11px kalın gövde metni
- Altın shimmer, hover büyümeleri, yüzen parçacıklar, geçiş animasyonları
- Responsive tasarım (masaüstü, tablet, mobil uyumlu)
- Modern buton stilleri, kart hover efektleri

### 📄 Çok Sayfalı Gezinme (SPA Mimarisi)
- Tek `index.html` dosyası içinde hash tabanlı sayfa yönetimi
- Ana Sayfa, Ürünler, Ürün Detay, Biz Kimiz, İletişim, Blog, Üye Ol, Giriş Yap, Sepet
- Tarayıcı geri/ileri tuşları desteklenir

### 🛒 E-Ticaret Özellikleri
- Ürün listesi ve detay sayfası
- Renk seçimi (altın, siyah, beyaz) – SVG görsel anında güncellenir
- Beden seçimi (S, M, L, XL, XXL)
- Adet artır/azalt kontrolü
- Sepete ekleme, çıkarma, miktar güncelleme
- Sepet verileri `localStorage` ile saklanır (sayfa yenilense bile korunur)
- Hızlı görünüm (Quick View) modal penceresi
- Toast bildirimleri (sepete eklendi, form gönderildi vb.)

### 🧩 Diğer Bölümler
- **Header:** Logo, navigasyon, Giriş Yap / Üye Ol butonları, sepet ikonu
- **Hero:** Altın parçacık efektli açılış bölümü
- **Kategoriler:** Erkek, Kadın, Limited Edition
- **Hakkımızda:** Animasyonlu istatistik sayaçları
- **İletişim:** Form tabanlı iletişim sayfası
- **Blog:** Örnek blog kartları
- **Footer:** Logo, sosyal medya ikonları, hızlı linkler, bülten aboneliği, ödeme ikonları

---

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|-----------|-----------|
| **HTML5** | Semantik yapı, erişilebilir formlar, SVG grafikler |
| **CSS3** | Animasyonlar, flexbox/grid, değişkenler, responsive tasarım |
| **JavaScript (Vanilla)** | SPA navigasyonu, DOM manipülasyonu, localStorage, Intersection Observer |

Harici kütüphane veya framework kullanılmamıştır. Tamamen saf HTML, CSS ve JavaScript'tir.
